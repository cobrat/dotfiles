# 子代理调度（全局）

只用内置 agent，禁止在调用里覆盖模型。

| agent | 用途 |
| --- | --- |
| `scout` | 只读侦察 |
| `reviewer` | 审查正确性 |
| `security-reviewer` | 审查安全 |
| `task` | 通用、可改文件 |
| `sonic` | 机械改动 |

必须委派，禁止自己动手：

- 审查 / 审计 / 检查改动 / 找安全隐患 → `reviewer`；涉及输入、鉴权、密钥、反序列化 → `security-reviewer`。范围再小也委派。**审查任务必须写明时间盒与只看哪些文件**；超时未回、或结论已被后续改动覆盖的，杀掉重派，不要等。
- 需要读取 3 个以上文件的摸底、搜索、定位 → `scout`。
- 2 个以上独立可并行的切片 → 一次 `tasks[]` 扇出，每项指定 `agent`。

自己做：顶层计划、单点小改（1 个文件、1 个函数）、需连续对话上下文的推理。

`scout`/`sonic` 只承接侦察与机械改动；禁止用子代理复述或确认自己的结论。子任务必须自包含。子任务可在**自己负责的包/目录内**跑限定范围的检查；跨包与全仓的 build、lint、全套测试由集成者在收尾统一跑一次。调用形状、`solutionSpace`、`agent://` 回收按工具文档执行。

## 输出

- 回复、计划、注释、提交说明遵循 ASD-STE100 简化技术英语：一句一义、主动语态、操作用祈使句、条件前置、一词一义；代码、命令、路径、标识符保持原样；语言沿用对话语言。
